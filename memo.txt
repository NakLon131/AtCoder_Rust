# コンテストのデータのダウンロード
cargo compete new xxxxxx

# フォルダ移動
cd xxxxxx

# テスト実行
cargo compete test 問題番号

# テスト実行(リリースビルド)
cargo compete test 問題番号 -- release

# 提出
cargo compete submit 問題番号 -- release

# 強制提出
cargo compete submit 問題番号 -- release --no-test

# 自作のテストケース追加
in/outのフォルダにテストケースのテキストを入れる。テストした内容は同じファイル名を指定する。
例
in/test1.txt
4
0 0
2 6
1 3
6 4

out/test1.txt
27

★スニペットの作り方
# https://paruma184.hatenablog.com/entry/2021/09/22/210945#%E3%82%B9%E3%83%8B%E3%83%9A%E3%83%83%E3%83%88%E7%AE%A1%E7%90%86%E3%83%84%E3%83%BC%E3%83%AB-cargo-snippet
1. snippetのインストール

2. cargoのプロジェクトを作る
	cargo new mylib

2-1. Cargo.tomiにsnippetのバージョンを指定
[dependencies]
cargo-snippet = "0.6.5"

3. 関数を作る。以下が例
use cargo_snippet::snippet;

#[snippet]
fn gcd_test(a: u64, b: u64) -> u64 {
    if b == 0 {
        a
    } else {
        gcd_test(b, a % b)
    }
}

fn main() {
    let _x = gcd_test(12, 18);
    println!("{}", _x);
}

4. ビルドが通ることを確認
cargo test

5. snippet部分を生成したファイルを置く。
cargo snippet -t vscode > ~/wsl_work/Rust/AtCoder_Rust/.vscode/xxx.code-snippets
